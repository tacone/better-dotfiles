# .zsh.d/

## Responsibility
Modular, framework-free zsh configuration loaded in sequence (no oh-my-zsh).
The directory is the entire shell setup: plugins are vendored locally in
`~/.dotfiles/.zsh-plugins/` and sourced manually, aliases/functions/environment
are grouped into numbered concern files, and external tool integrations
(starship, fzf, zoxide, thefuck, opencode) are wired in. The numeric prefix is
both the load order and the layering order — later files may rely on state set by earlier ones.

## Design
Files are named `NN-name.zsh` and executed alphabetically by the glob in
`zshrc`. Everything is plain zsh; the oh-my-zsh framework is not installed.

- **00-init**: sets `ZSH_PLUGINS=$HOME/.dotfiles/.zsh-plugins`,
  `EDITOR='nvim'`, `setopt AUTO_PUSHD`; binds Home/End/Delete/Ctrl+Delete/
  Ctrl+Left/Ctrl+Right/Shift+Enter (`beginning-of-line`, `end-of-line`,
  `delete-char`, `kill-word`, `forward-word`, `backward-word`,
  `accept-and-hold`); loops over `plugins=(colored-man-pages command-not-found
  git httpie grc magic-enter nmap zsh-syntax-highlighting)` sourcing
  `$ZSH_PLUGINS/$plugin/$plugin.plugin.zsh` (special-cases `z.sh` for z).
- **10-environment**: PATH construction — `./scripts`, `~/.local/bin`, omarchy
  bin, `~/.bun/bin`, `$XDG_CACHE_HOME/.bun/bin`, `~/.bin`; sources
  `~/.cargo/env`; npm global prefix `~/.npm-packages` (+ `NODE_PATH`, `MANPATH`,
  localhost:4873 registry probe); `BAT_THEME_DARK="Dracula"`; saves
  `STANDARD_PATH=$PATH`, runs `eval $_refresh_paths`.
- **20-aliases**: eza-based `ls`/`lt`/`lta` with grc/color fallback;
  `parent-find` (walks parents for a file); `before`/`after` (grep -B/-A
  pipes); `ff` (fzf + bat preview); `filewatch` + `filewatch0`..`10`
  (poll-interval presets via `FILEWATCH_SLEEP_TIME`); global aliases `@yml`,
  `@json`, `»`, `»»`, `§`; cd-chain `..`..`...........`; `d` (docker),
  `d` (dirs -v), `1`-`9`, `n`, `x`, `open`; sources `~/.aliases` then
  `~/.custom-aliases`; `INTERPOLATE_GIT_LOG=1 source ~/.bin/git-links`.
- **30-functions**: `byobu_col` + `col1`-`col9`/`NF` column extraction;
  `find-port`/`kill-port` (lsof + grc highlight); `gh` wrapper
  (owner/repo → `git clone`, else real gh); `gitignore.io`; `filewatch`/
  `filewatch2` (inotifywait watch loops); `ask-yn` (y/N prompt);
  `g`/`gg` (`gg` = AI commit message via `gh copilot -p ... --model=gpt-5-mini`);
  `ask` (`opencode run "$*"` with edit/bash permission denied);
  `modmask_to_keys`, `hyprland-bindings` (hyprctl binds decoder); plus
  `multiline`, `custom_nnn`, `timestamp`, `wwwwrite`.
- **40-docker**: `Ð` — index into `docker-compose ps`, then `docker exec -it`
  the Nth machine (default bash); aliases `Ð1`-`Ð10`; dangling-image,
  stopped-container, and dangling-volume list+remove aliases
  (`docker-list-dangling-images`, `docker-remove-dangling-images`,
  `docker-list-stopped-containers`, `docker-remove-stopped-containers`,
  `docker-list-dangling-volumes`, `docker-remove-dangling-volumes`).
- **50-git**: `git_http_to_ssh` (rewrites https remotes to `git@` form),
  `git-make-date` (random plausible date from history), `git-change-date`
  (amend with forged committer/author date).
- **55-zoxide**: AUTO-GENERATED by `.install.sh` (`zoxide init zsh`) — do not
  edit. Defines `__zoxide_pwd`, `__zoxide_cd`, `__zoxide_hook` (via
  `chpwd_functions`), `__zoxide_doctor`, `__zoxide_z`, `__zoxide_zi`, user
  commands `z`/`zi`, and zle completion helpers.
- **60-completions**: kill completion with process details
  (`zstyle ':completion:*:kill:*' command 'ps -u $USER -o pid,%cpu,tty,cputime,cmd'`,
  red-list-colors); `compinit` + `complist`; `WORDCHARS=''`,
  `unsetopt menu_complete`, `setopt auto_menu complete_in_word always_to_end`;
  global `menu select`, case-insensitive `matcher-list`; menuselect `+` =
  `accept-and-menu-complete`; bun completions from `~/.bun/_bun`;
  `unsetopt completealiases`; `zshaddhistory` hook (space-prefixed lines not
  saved to history).
- **70-keybindings**: `_bind_custom_keys` binds Alt-letter `bindkey -s` macros
  — Alt+d diff, Alt+D diff --cached, Alt+g `| grep -i`, Alt+x/Alt+X xargs,
  Alt+h `--help`, Alt+C opencode, Alt+z `zi`, Alt+e nnn, Alt+f/Alt+F find/ff,
  Alt+l/L git log, Alt+s/Alt+S sudo/sed; zle widgets `insert-sudo` (^[s),
  `insert-bat` (^[b), `insert-watch` (^[w, viddy-aware), `_show_keybindings`
  help (Alt+k), `foreground-current-job` (`^Z` fg toggle in emacs/viins/vicmd
  keymaps); Alt+Shift+H = `run-help`.
- **80-integrations**: `eval "$(starship init zsh)"`; sources fzf
  `completion.zsh` + `key-bindings.zsh`; grc plugin when `/etc/grc.conf`
  exists; thefuck alias (`eval $(thefuck --alias)`) when `fuck` installed;
  vte.sh for TILIX/VTE; opencode yargs completions via
  `compdef _opencode_yargs_completions opencode`; `alias o=opencode`.
- **90-custom**: preexec/precmd command-duration reporting —
  `preexec_start_timer` + `precmd_report_time`; `TIME_REPORT_THRESHOLD=10`;
  commands >10s print `😎/🔴 \`cmd\` completed in N seconds.` and fire
  `notify-send` with exit status; sources `zsh-syntax-highlighting`;
  `command_not_found_handler` → `pkgfile -b -v` lookup with `yay -S` install
  prompt (`PKGFILE_PROMPT_INSTALL_MISSING=1`).
- **99-startup**: terminal-start matrix rain — `neo-matrix -D -s -M 1
  -m "$(fortune)" --color <random>` when `$TERM_PROGRAM != vscode` (cmatrix
  `-s` fallback).

## Flow
Exact sourcing order (as done by `~/.dotfiles/zshrc`, symlinked to `~/.zshrc`):
the loop `for config_file ($HOME/.dotfiles/.zsh.d/*.zsh); do source $config_file; done`
sources them alphabetically (00-init → 99-startup), which the numbering above
mirrors; then `~/.zsh.local` is sourced last (which itself may source
`~/.zshrc.local`). `zshrc` also runs `compinit`, sets history options
(`HISTSIZE=100000`, `INC_APPEND_HISTORY`, `HIST_IGNORE_DUPS`, `HIST_REDUCE_BLANKS`),
sources omarchy functions, and exports `OPENCODE_EXPERIMENTAL_BACKGROUND_SUBAGENTS`.

## Integration
- Sourced by: `/home/tacone/.dotfiles/zshrc` (symlinked to `~/.zshrc`)
- Depends on: `~/.dotfiles/.zsh-plugins/` (vendored plugins), `~/.aliases`,
  `~/.custom-aliases`, `~/.zsh.local`
- Calls external CLIs: eza, fzf, bat, starship, grc, thefuck, zoxide, nnn,
  opencode, gh copilot, pkgfile/yay
- 55-zoxide.zsh is regenerated by `.install.sh`
